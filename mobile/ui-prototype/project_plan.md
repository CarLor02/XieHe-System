# 脊柱医疗影像 AI 分析系统（移动端）

## 1. 项目描述
面向医生与技师的脊柱 X 光 AI 分析移动 Web（竖屏）。核心业务：脊柱 X 光（正位/侧位/左侧曲位/右侧曲位）上传、AI 自动测量（Cobb 角、SVA/PI 等）、手动标注、诊断报告生成与审核、患者与消息管理。

- 目标用户：骨科/影像科医生、技师
- 核心价值：将脊柱侧弯/矢状面参数测量与报告流程搬到手机端，提升诊疗效率

## 6. 开发阶段计划

### 阶段 1：患者新增/编辑页
- 目标：补齐导航已指向但缺页的患者表单，打通「新增/编辑 → 保存 → 返回列表」闭环
- 交付：患者表单页（含校验、性别分段选择、日期/年龄、toast 反馈）

### 阶段 2：影像上传 + 影像查看器
- 目标：影像上传（拍照/相册/文件 + 类型选择 + 进度动画）、影像详情查看器（大图/缩放/翻转）

### 阶段 3：AI 测量结果展示 + 诊断报告
- 目标：AI 指标可视化（Cobb/SVA/PI/LL 叠图 + 数值卡片 + 参考范围）、诊断报告编辑与审核状态

### 阶段 4：消息详情 + 空状态/骨架屏
- 目标：消息详情（业务操作按钮）、空状态插画、骨架屏组件

### 阶段 5：i18n 国际化
- 目标：为全部页面补充 zh/en 文案，保持 i18next 结构

### 阶段 6：通用组件抽象 + 业务闭环收尾
- 目标：抽出底部 Tab、顶部导航、搜索框、筛选弹层、状态标签、空状态、骨架屏等通用组件，统一风格
- 已完成：BottomTabBar（4 页接入，useLocation 自动高亮）、PageHeader（标题/副标题/返回/右侧操作/搜索子内容，roundedBottom 可配置）、SearchBar、FilterSheet（选项型底部弹层）、StatusTag（tone + dot 可配置）、EmptyState（早前完成）
- 待完成：骨架屏组件（Skeleton）
