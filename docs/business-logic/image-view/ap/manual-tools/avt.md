# 顶椎平移量（AVT）

## 适用范围

- 仅适用于正位 X 光片标注。
- 工具名称为 `AVT`，含义为顶椎平移量（Apical Vertebral Translation）。
- AVT 支持“椎体中心”和“椎间盘”两种目标类型。
- 一张影像可以存在多个 AVT，但同一目标类型、同一目标层级最多对应一个 AVT。
- AVT 距离使用影像的标准距离换算为毫米；未设置标准距离时，沿用标注页现有的标准距离提示流程。

## 目标与参考线

AVT 的目标由医生选择，参考线由目标的生理学层级自动确定，不提供手动切换。

| 目标类型 | 目标范围         | 参考线 |
| -------- | ---------------- | ------ |
| 椎体中心 | T2-T11           | C7PL   |
| 椎体中心 | T12-L4           | CSVL   |
| 椎间盘   | T2-T3 至 T11-T12 | C7PL   |
| 椎间盘   | T12-L1 至 L3-L4  | CSVL   |

其中：

- `C7PL` 是经过 C7 椎体四角点中心的垂线。
- `CSVL` 是经过 SR、SL 中点的骶骨中垂线。
- `T11-T12` 椎间盘使用 C7PL。
- `L4-L5` 不属于当前 AVT 可选范围。

## 交互流程

1. 医生点击工具栏中的 `AVT`。
2. 面板先显示“椎体中心”和“椎间盘”两个目标类型选项。
3. 选择“椎体中心”后，面板显示与原 AVT 一致的椎体选项列表，但仅包含 T2-L4。
4. 选择“椎间盘”后，面板显示连续节段选项，例如 `T2-T3`、`T3-T4`、`T11-T12`、`T12-L1`。
5. 已存在相同目标类型和目标层级的 AVT 置灰，不允许重复创建。
6. 使用 C7PL 的选项要求 C7 四个角点完整；使用 CSVL 的选项要求 SR、SL 同时存在。缺少参考点时，对应选项置灰。

### 椎体中心

选择椎体后，系统立即读取该椎体四角点以及对应参考线关键点，创建 AVT。

### 椎间盘

1. 选择椎间盘层级后，面板关闭，画布进入十字光标两点放置状态。
2. 第一次点击确定线段第一个端点和水平高度。
3. 第二次点击只采用 X 坐标，Y 坐标自动吸附到第一次点击的 Y，形成水平线。
4. 系统按屏幕 X 坐标排序，左侧端点为 `a`，右侧端点为 `b`，因此不限制医生的点击顺序。
5. `ab` 的中点 `c` 为椎间盘 AVT 的目标中点。
6. 第二点完成后立即创建 AVT，并自动退出到移动状态。
7. 两点放置完成前可按 Esc 取消，不产生 measurement 或 history 记录。

## 数据模型

新 AVT 使用带版本的 metadata 保存目标与参考线：

```ts
type AvtTarget =
  | { type: 'vertebra'; vertebra: string }
  | { type: 'disc'; upperVertebra: string; lowerVertebra: string };

type AvtReferenceLine = 'c7pl' | 'csvl';

interface AvtMetadata {
  schemaVersion: 2;
  target: AvtTarget;
  referenceLine: AvtReferenceLine;
}
```

椎体中心 AVT 可以继续镜像保存 `apexVertebra` 作为历史兼容字段；椎间盘 AVT 不使用 `apexVertebra` 表达层级。

## 点位结构

AVT 保存用于目标定位和参考线定位的原始点，不保存可重新计算的派生中点。

| 目标     | 参考线 | points 布局                                    |
| -------- | ------ | ---------------------------------------------- |
| 椎体中心 | CSVL   | `[V-1, V-2, V-3, V-4, SR, SL]`                 |
| 椎体中心 | C7PL   | `[V-1, V-2, V-3, V-4, C7-1, C7-2, C7-3, C7-4]` |
| 椎间盘   | CSVL   | `[a, b, SR, SL]`                               |
| 椎间盘   | C7PL   | `[a, b, C7-1, C7-2, C7-3, C7-4]`               |

点数可能为 4、6 或 8，不能只根据点数判断目标类型，必须结合 `avtMetadata` 解释。

## 计算规则

### 目标中点

- 椎体中心：目标椎体四个角点坐标的平均值。
- 椎间盘中心：用户手动画出的水平线 `ab` 的中点 `c`。

### 参考线

- C7PL 的参考 X 坐标为 C7 四角点中心的 X 坐标。
- CSVL 的参考 X 坐标为 SR、SL 中点的 X 坐标。

### AVT 数值

- 像素偏移量为“目标中点 X - 参考线 X”。
- 系统使用标准距离换算偏移量绝对值，再保留原始左右方向符号。
- 目标中点位于参考线左侧时结果为负，位于右侧时结果为正。

## 图像显示

- 椎体中心 AVT 使用虚线连接目标椎体四角点并显示椎体中心。
- 椎间盘 AVT 显示用户确定的水平线 `ab` 及其中点 `c`。
- C7PL AVT 显示 C7 四角点轮廓、C7 中心和经过中心的垂直引导线。
- CSVL AVT 显示 SR、SL 骶骨参考线、其中点和 CSVL 垂直引导线。
- 在目标中点高度绘制目标中点到参考线的水平测量线。
- AVT 数值同时显示在影像和左上角测量结果列表中。
- 结果列表显示为 `AVT(T4)` 或 `AVT(T4-T5)`。

## 绑定与调整规则

- 椎体中心 AVT 的目标四点与目标椎体关键点双向绑定。
- 椎间盘 AVT 的 `a`、`b` 是 measurement 自有点，不与相邻椎体关键点绑定。
- C7PL 的四个参考点与 C7 四角点双向绑定。
- CSVL 的两个参考点与 SR、SL 双向绑定。
- 移动 C7 关键点时，所有依赖 C7PL 的 AVT 保持原 `id` 和 metadata 并重新计算。
- 移动 SR、SL 时，所有依赖 CSVL 的 AVT保持原 `id` 和 metadata 并重新计算。
- 拖动椎间盘端点的 X 时只修改当前端点；拖动其 Y 时同时移动 `a`、`b` 的 Y，使线段始终水平。
- 椎间盘端点交叉后重新按 X 排序为 `a`、`b`。
- AVT 不允许整体拖动，避免参考线绑定点与关键点层分离。

## 缺失点与删除

- C7 任一角点缺失时，依赖 C7PL 的 AVT 无法继续计算，应从当前测量列表移除。
- SR 或 SL 缺失时，依赖 CSVL 的 AVT 无法继续计算，应从当前测量列表移除。
- 椎体中心 AVT 的目标椎体关键点不完整时，只移除绑定该目标的 AVT。
- 椎间盘附近的椎体关键点缺失不影响已存在的椎间盘 AVT，因为 `a`、`b` 为 measurement 自有点。
- 用户从结果列表删除 AVT 时，只删除该 measurement，不删除任何关键点。

## 唯一性与 ID

- 唯一键由目标类型和目标层级共同组成，例如 `vertebra:T4`、`disc:T4:T5`。
- 新椎体中心 AVT 使用稳定 ID `ap-keypoint-avt-<椎体>`。
- 新椎间盘 AVT 使用稳定 ID `ap-keypoint-avt-disc-<上方椎体>-<下方椎体>`。
- AVT 不使用全局序号。

## 历史数据兼容

- 历史 AVT 可能使用固定 ID `ap-keypoint-avt`，重算时必须保持该 ID 不变。
- 历史两点格式 `[apexCenter, csvlRef]` 继续按旧 CSVL 语义完成计算、图形和标签定位。
- 历史六点格式 `[V-1, V-2, V-3, V-4, SR, SL]` 且没有 `avtMetadata` 时，继续解释为“椎体中心 + CSVL”。
- 旧 AVT 不根据新的层级规则静默迁移为 C7PL，避免改变历史测量值。
- 历史兼容分支应在代码中保留明确注释，不得通过点数将旧两点 AVT 误判为椎间盘 AVT。
