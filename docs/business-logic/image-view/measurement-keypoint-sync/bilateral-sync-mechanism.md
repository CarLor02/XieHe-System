# 测量项与关键点双向同步机制

## 1. 目的

测量项和关键点描述的是同一组解剖位置的不同视图：

- 关键点用于检测层展示、关键点修正和基于关键点的测量派生。
- 测量项保存工具绘制点、计算结果和测量项元数据。

只要一个测量工具的点能够确定具体解剖关键点，该工具就必须遵循双向同步：

1. 手动完成测量项时，创建或更新对应关键点。
2. 关键点满足工具的最小依赖时，创建或更新对应测量项。
3. 任一侧点位变化时，另一侧使用同一坐标并重新计算结果。

通用 `CobbN` 和 `lateral-cobbN` 暂不接入本机制。它们在填写上下端椎之前不能确定四个测量点对应的椎体关键点，继续使用测量列表中的“同步检测层”操作。

## 2. 统一领域语义

### 2.1 坐标与左右方向

- 图像坐标原点位于左上角，X 向右增加，Y 向下增加。
- 进入前端领域层后，屏幕左侧对应 `_L`，屏幕右侧对应 `_R`。
- AI 正位模型对 `CR/CL`、`IR/IL`、`SR/SL` 使用了相反方向。该差异必须只在 AI 响应适配层交换，不能进入本机制的规则表。

### 2.2 椎体四角点

四个无序点按几何位置归一化为：

| 排序位置 | 关键点序号 |
| --- | --- |
| 左上 `TL` | `V-1` |
| 右上 `TR` | `V-2` |
| 左下 `BL` | `V-3` |
| 右下 `BR` | `V-4` |

现有 AI 检测中的几何排序函数应下沉到 `measurement-keypoint-sync/domain`，由 AI 适配和手动工具共同使用。

### 2.3 侧位终板

侧位同一终板的两个点按屏幕 X 坐标从左到右排序：

- 上终板对应 `V-1`、`V-2`。
- 下终板对应 `V-3`、`V-4`。
- 屏幕左侧为 posterior，屏幕右侧为 anterior。

### 2.4 解剖点与交互点

只有能稳定命名的解剖点写入关键点层。以下点只服务于工具交互，不写入关键点：

- TTS 的两个人工躯干水平线端点。
- 椎间盘 AVT 的人工端点 `a`、`b`。
- L/R 四条纵线为了伸缩而保存的上下端点。
- LLD 和辅助图形的自由绘制点。

## 3. 绑定规则结构

每个固定测量工具的领域规则至少包含：

- 测量类型 ID。
- 最小关键点依赖。
- 测量点布局及其中的交互点。
- 测量点几何归一化函数。
- 测量点到关键点的映射。
- 关键点到测量点的重建函数。
- 当前绘制阶段的提示。

规则统一放在：

`frontend/app/imaging/features/image-viewer/features/measurement-keypoint-sync/domain`

应用层只负责编排状态、计算结果和持久化，不重复声明点序。

## 4. 手动测量到关键点

1. 工具完成当前点组后先执行几何归一化。
2. 使用归一化后的点计算并保存测量项。
3. 对规则中声明的关键点执行 upsert：
   - `source = manual`
   - `confidence = 1`
4. 写回关键点和检测层后，重算所有依赖这些关键点的已有测量项。
5. 工具只补充实际使用的关键点，不要求同一椎体四点全部存在。

当一个手动测量覆盖已有 AI 关键点时，该点已经经过人工确认，应改为手动来源。

## 5. 关键点到测量项

- 关键点满足工具的最小依赖后，可派生全局唯一的固定测量项。
- 派生不得通过“完整椎体组”间接判断，否则只需要终板两点的工具会被无关角点阻塞。
- 关键点移动后，保留已有测量项的 `id`、`type` 和业务元数据，只更新点位与计算值。
- 删除必要关键点后，直接移除依赖缺失的测量项。
- 新增或删除普通关键点时不自动派生 Cobb；全量 Cobb 自动派生只允许发生在 AI 初始检测流程。

## 6. 历史数据回填

加载历史标注时，已有测量项可以补齐缺失关键点：

- 不覆盖已经存在的关键点。
- 按测量列表顺序处理；第一个能够补齐某关键点的测量项优先。
- 后续依赖同一关键点的测量项以关键点为准重建并重算。
- 回填出的关键点来源记为手动，以表示坐标来自历史人工测量数据。

该规则用于兼容历史存储格式，不改变测量项 ID。

## 7. 绘制提示

- 点语义在点击前已经确定时，提示中显示关键点 ID。
- 左右点或四角点需要完成点组后才能确定语义时，显示“待排序点 N/M”，完成后再绑定具体关键点。
- L/R 的四个锚点在完成前不显示具体关键点名。
- 工具提示必须读取领域规则，不能在 `CanvasHintPanel` 中重复维护工具点序。

## 8. 明确排除

- 通用 `CobbN/lateral-cobbN`。
- 不对应解剖关键点的辅助图形。

AVT 使用 measurement metadata 动态确定绑定。手动创建时必须先补 C7PL/CSVL
参考点，再补目标椎体点或椎间盘自有点；AVT 不作为全局唯一项自动派生。
