# 测量项与关键点双向同步机制

## 1. 目的

测量项和关键点描述的是同一组解剖位置的不同视图：

- 关键点用于检测层展示、关键点修正和基于关键点的测量派生。
- 测量项保存工具绘制点、计算结果和测量项元数据。

只要一个测量工具的点能够确定具体解剖关键点，该工具就必须遵循双向同步：

1. 手动完成测量项时，创建或更新对应关键点。
2. 手动工具完成后，以该工具确认的完整关键点集合为边界，局部派生依赖点
   全部落在边界内的其他测量项。
3. 关键点变化时，只更新已经存在的对应测量项，不创建缺失测量项。
4. 任一侧点位变化时，另一侧使用同一坐标并重新计算结果。

通用 `CobbN` 和 `lateral-cobbN` 在填写上下端椎前不绑定关键点；端椎填写完整后，按照当前正位或侧位规则自动写回对应的四个关键点。

## 2. 统一领域语义

### 2.1 坐标与左右方向

- 图像坐标原点位于左上角，X 向右增加，Y 向下增加。
- 进入前端领域层后，屏幕左侧对应 `_L`，屏幕右侧对应 `_R`。
- AI 正位模型对 `CR/CL`、`IR/IL`、`SR/SL` 使用了相反方向。该差异必须只在 AI 响应适配层交换，不能进入本机制的规则表。

### 2.2 椎体四角点

四个无序点按几何位置归一化为：

| 排序位置  | 关键点序号 |
| --------- | ---------- |
| 左上 `TL` | `V-1`      |
| 右上 `TR` | `V-2`      |
| 左下 `BL` | `V-3`      |
| 右下 `BR` | `V-4`      |

现有 AI 检测中的几何排序函数应下沉到 `measurement-keypoint-sync/domain`，由 AI 适配和手动工具共同使用。

### 2.3 侧位终板

侧位同一终板的两个点按屏幕 X 坐标从左到右排序：

- 上终板对应 `V-1`、`V-2`。
- 下终板对应 `V-3`、`V-4`。
- 屏幕左侧为 posterior，屏幕右侧为 anterior。

### 2.4 解剖点与交互点

只有能稳定命名的解剖点写入关键点层。以下点只服务于工具交互，不写入关键点：

- TTS 的两个人工躯干水平线端点。
- 椎间盘 AVT 的人工端点 `a`、`b`。
- L/R 四条纵线为了伸缩而保存的上下端点。
- LLD 和辅助图形的自由绘制点。

## 3. 绑定规则结构

每个固定测量工具的领域规则至少包含：

- 测量类型 ID。
- 最小关键点依赖。
- 测量点布局及其中的交互点。
- 测量点几何归一化函数。
- 测量点到关键点的映射。
- 关键点到测量点的重建函数。
- 当前绘制阶段的提示。

规则统一放在：

`frontend/app/imaging/features/image-viewer/features/measurement-keypoint-sync/domain`

应用层只负责编排状态、计算结果和持久化，不重复声明点序。

## 4. 手动测量到关键点

1. 工具完成当前点组后先执行几何归一化。
2. 使用归一化后的点计算并保存测量项。
3. 对规则中声明的关键点执行 upsert：
   - `source = manual`
   - `confidence = 1`
4. 写回关键点和检测层后，重算所有依赖这些关键点的已有测量项。
5. 以当前工具的完整 `requiredKeypointIds` 为派生范围，创建依赖集合是该范围
   子集且允许自动派生的缺失测量项。
6. 工具只补充实际使用的关键点，不要求同一椎体四点全部存在。

当一个手动测量覆盖已有 AI 关键点时，该点已经经过人工确认，应改为手动来源。

## 5. 关键点到测量项

- AI 初次检测可以根据全量关键点派生测量项，包括初始 Cobb 派生。
- 手动工具完成后允许局部派生，但只能使用该工具确认的完整绑定点集。目标
  测量项的最小依赖必须是该点集的子集，禁止借用其他历史关键点扩大派生范围。
- 例如完成 PI 或 PT 后可派生另一项和 SS；完成 SS 后不能反向派生 PI/PT。
- 手工新增或补齐关键点时，即使已经满足工具的全部依赖，也不得创建缺失测量项。
- 用户点击缺失的测量工具时必须进入手工绘制；工具完成后的局部派生不等同于
  点击工具时根据全局关键点零点击恢复。
- 部分点可继承时保留继承；若全部点均可继承，则要求重新绘制全部点，不能零点击恢复。
- 关键点移动后，保留已有测量项的 `id`、`type` 和业务元数据，只更新点位与计算值。
- 删除必要关键点后，直接移除依赖缺失的测量项。

## 6. 删除规则

删除使用领域绑定构建的精确依赖图，禁止根据坐标重合推断关键点关系。

- 删除测量项：删除目标测量项，并删除仅被该测量项使用的关键点；仍被其他测量项引用的点保留。
- PI 与 PT 视为一个删除组，删除任意一项时同时删除另一项。
- 删除单一关键点：删除所有直接依赖该点的测量项，但不继续删除这些测量项的其他关键点。
- 删除椎体组：等价于一次选择该组现存的全部关键点，按上一条规则计算级联。
- Cobb 删除完成后统一重编号，measurement `id` 和端椎元数据不变。
- AVT 依赖由其 metadata 决定；TTS 只依赖 `SL/SR`，两个人工水平线端点不属于全局关键点。

## 7. 历史数据回填

加载历史标注时，已有测量项可以补齐缺失关键点：

- 不覆盖已经存在的关键点。
- 按测量列表顺序处理；第一个能够补齐某关键点的测量项优先。
- 后续依赖同一关键点的测量项以关键点为准重建并重算。
- 回填出的关键点来源记为手动，以表示坐标来自历史人工测量数据。

该规则用于兼容历史存储格式，不改变测量项 ID。

## 8. 绘制提示

- 点语义在点击前已经确定时，提示中显示关键点 ID。
- 左右点或四角点需要完成点组后才能确定语义时，显示“待排序点 N/M”，完成后再绑定具体关键点。
- L/R 的四个锚点在完成前不显示具体关键点名。
- 工具提示必须读取领域规则，不能在 `CanvasHintPanel` 中重复维护工具点序。

## 9. 明确排除

- 不对应解剖关键点的辅助图形。

AVT 使用 measurement metadata 动态确定绑定。手动创建时必须先补 C7PL/CSVL
参考点，再补目标椎体点或椎间盘自有点；AVT 不作为全局唯一项自动派生。
Cobb 的端椎在工具完成时尚未确定，继续使用端椎选择后的专用同步流程，不参与
固定绑定规则的局部派生。
