# 测量项入口与 Cobb 派生规则

## 1. 职责边界

侧位通用 Cobb 有两类创建入口：

- **测量项派生**：只使用检测层中已经存在的全部必需端板点，直接创建测量项，不进入画布补点。
- **手动标注**：可以不绑定端椎直接绘制四点，也可以先选择一端或两端椎体，继承已有关键点并只绘制缺失点。

两类入口最终都生成相同的 `lateral-cobbN` 测量项，沿用统一编号、角度计算、结果列表和端椎绑定规则。

## 2. 手动标注入口

点击侧位通用 Cobb 后先选择标注方式：

| 方式       | 行为                                                                     |
| ---------- | ------------------------------------------------------------------------ |
| 暂无关键点 | 沿用原有流程，依次绘制 Cobb 的四个点，完成后在结果列表选择上下端椎。     |
| 已有关键点 | 打开“选择端椎”面板，先选择上端椎、下端椎，再继承已有端板点并补充缺失点。 |

“已有关键点”模式允许单个端椎为“待定”，但上下端椎不能同时待定。已确定端椎对应的点绑定到检测层关键点；待定端椎对应的两个点暂时只属于测量项，之后在结果列表选定端椎时再写回检测层。

### 2.1 四点槽位

侧位通用 Cobb 始终按以下槽位保存：

1. 上端椎上终板第一个点，绑定 `V1-1`
2. 上端椎上终板第二个点，绑定 `V1-2`
3. 下端椎下终板第一个点，绑定 `V2-3`
4. 下端椎下终板第二个点，绑定 `V2-4`

下端椎为 `S1` 时是特殊规则，第三、第四槽位分别绑定 `S1-1`、`S1-2`。

### 2.2 继承和覆盖

- 已有关键点按照槽位直接继承，画布只要求用户绘制缺失槽位。
- 四个必需点都存在时，无需画布点击，直接创建 Cobb。
- 继承且坐标未变化的关键点保留原 `source` 和 `confidence`。
- 用户新绘制或覆盖的关键点写为手动来源。
- 取消放置时不写入未完成的测量项或关键点。

## 3. 测量项派生

测量项派生不再要求上下端椎各自拥有完整四角，只要求当前 Cobb 实际使用的端板点存在：

- 上端椎需要 `V-1`、`V-2`。
- 普通下端椎需要 `V-3`、`V-4`。
- 下端椎为 `S1` 时需要 `S1-1`、`S1-2`。

只有 resolver 确定的四个点全部存在时才允许“应用派生”。派生模式不负责补点；需要补点时应使用手动 Cobb 的“已有关键点”入口。

## 4. 公共校验

- 上端椎的生理学顺序必须位于下端椎上方，且两者不能相同。
- 已存在相同上下端椎的 Cobb 时禁止重复创建。
- 如果端椎组合对应 `TK T2-T5`、`TK T5-T12`、`T10-L2`、`LL L1-S1`、`LL L1-L4`、`LL L4-S1` 或 `C2-C7 CL` 等命名侧位 Cobb，则提示“请使用专用工具创建此测量项!”。
- 单端待定时，需在结果列表补全另一端后再执行组合重复和专用工具校验。
