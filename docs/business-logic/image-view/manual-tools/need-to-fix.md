# 手动测量工具待修复项

## AVT 缺少参考点时的创建流程

当前 AVT 在参考线关键点不完整时不能创建：

- C7PL 依赖 C7 四个角点。
- CSVL 依赖 `SL`、`SR`。

双向同步机制落地后，AVT 不应继续把缺少参考点作为绝对禁用条件。未来应在 AVT
绘制过程中允许医生补充缺失参考点，并将这些点写回关键点层。

本轮不修改 AVT，原因如下：

- 椎体中心和椎间盘 AVT 的目标点布局不同。
- 椎间盘的 `a,b` 是人工交互点，不属于关键点。
- 缺少目标点和缺少参考线点时的点击顺序、取消行为和提示尚未确定。

在交互方案明确前，继续保持现有 C7PL/CSVL 完整性校验，避免把不清晰的点击顺序固化进领域规则。
